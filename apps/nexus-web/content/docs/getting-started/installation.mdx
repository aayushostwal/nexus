## Prerequisites

- Claude Code, or the Codex CLI
- Node.js 18+ (only used by the bundled helper scripts — there is nothing to `npm install`)

There is no npm package and no global `nexus` CLI. Nexus is distributed as a git-based plugin marketplace, installed directly from the GitHub repo `aayushostwal/nexus`.

## Install In Claude Code

```text
/plugin marketplace add aayushostwal/nexus
/plugin install nexus@nexus-marketplace
/reload-plugins
```

After the reload, the 10 skills, 14 agents, and 4 commands are available under the `nexus:` namespace.

## Install In Codex

Codex installs use the third-party `codex-marketplace` tool:

```bash
npx codex-marketplace add aayushostwal/nexus --plugin --global
```

Project-scoped install:

```bash
npx codex-marketplace add aayushostwal/nexus --plugin --project
```

This is a direct repo install — you need the repo slug `aayushostwal/nexus`; the plugin is not listed in a central Codex index.

## Bundled Helper Scripts

The plugin's helper scripts are dependency-free Node scripts. Commands run them with plain `node`:

```bash
node "${CLAUDE_PLUGIN_ROOT}/bin/nexus.js"
```

No install step, no `node_modules` — Node 18 or newer is the only requirement.

## Automatic Bootstrap

On first active plugin run, Nexus creates or updates runtime-specific instruction files:

- Claude runtime: `~/.claude/CLAUDE.md`
- Codex runtime: `~/.codex/AGENT.md`

If either file already exists, Nexus preserves your content and only appends/updates the Nexus-managed skills-first block. You can also trigger this manually from the plugin directory:

```bash
node scripts/bootstrap-agent-docs.js
```
