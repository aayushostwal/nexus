## Prerequisites

- Node.js 20+
- GitHub account
- Terminal with `npm` or `pnpm`

## Install

```bash
npm i -g nexus-agent-kit
```

## Verify

```bash
nexus --version
nexus doctor
```

## Initialize Workspace

```bash
nexus init
```

This creates agent presets, workflow templates, and optional MCP wiring.
