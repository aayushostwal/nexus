## First Command

With the plugin installed, review your current branch:

```text
/nexus:review-branch
```

Nexus ships 4 commands: `/nexus:add-todo`, `/nexus:daily-brief`, `/nexus:review-branch`, and `/nexus:stats`.

## Trigger A Skill

Skills auto-trigger when your request matches their description, or you can invoke one directly:

```text
/nexus:debugging fix the failing CI pipeline
```

## Delegate To An Agent

Agents are subagents that Claude Code delegates to based on your request. Just ask in natural language:

```text
review this PR for regressions          → code-reviewer
where is the auth flow implemented      → codebase-explorer
write a PRD for this feature idea       → prd-writer-critic
```

Each agent runs in its own context window and remembers what it learns — user-scoped agents carry preferences across repos, project-scoped agents build per-repo memory in `.claude/agent-memory/`.
