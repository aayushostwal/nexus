# Skill Writer Protocol

## Goal
Produce high-signal skills that are easy for agents to trigger and follow.

## Workflow
1. Define trigger conditions and non-triggers clearly.
2. Write a minimal workflow (3-6 steps) with concrete actions.
3. Add output shape and anti-patterns.
4. Keep examples short and generic.
5. Remove redundant narrative and stack-specific bias unless requested.

## Required Sections
- Name + description
- When to use
- Workflow
- Output shape
- Anti-patterns

## Quality Checks
- Trigger language is explicit.
- Steps are actionable and ordered.
- No ambiguous terms like "as needed".
- No unnecessary verbosity.

## Output Shape
```text
Outcome:
Changes:
Why:
Validation:
Next Step:
```
