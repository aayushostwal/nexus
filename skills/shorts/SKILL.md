# Shorts Protocol

## Goal
Turn one core idea into a 30-60 second script that is clear, engaging, and actionable.

## Workflow
1. Extract one message and target audience.
2. Write 3 hook options.
3. Build script blocks: Hook -> Value -> Example -> CTA.
4. Add visual cues and pacing notes.

## Script Template
- Hook (0-5s)
- Problem framing (5-12s)
- Core insight (12-30s)
- Example/demo (30-50s)
- CTA (50-60s)

## Rules
- Keep language/tool examples generic unless user specifies a stack.
- Avoid inflated claims and unverifiable stats.
- Keep CTA single-action.
