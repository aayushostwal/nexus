# Shorts Script Quality Checklist

Use this checklist before delivering any YouTube Short script to the user. Every item must pass.

---

## Word Count & Timing

- [ ] Total word count is between 70 and 80 words
- [ ] Hook is 8–12 words (count them — do not estimate)
- [ ] Core content is 50–55 words
- [ ] CTA is 12–15 words
- [ ] The assembled script was read aloud — it completes naturally in 28–32 seconds at a comfortable speaking pace
- [ ] If over 80 words: one sentence was removed from core content (never from hook or CTA)
- [ ] If under 70 words: one concrete detail or example was added to core content (never filler)

---

## Hook Quality

- [ ] The hook does not start with "In this video" or "Today we're going to"
- [ ] The hook is under 12 words (hard limit — count them)
- [ ] Three distinct hook variants are provided (not three rewordings of the same hook)
- [ ] The user is presented all three variants — not one pre-selected for them
- [ ] At least one hook variant passes the audio-only test (makes sense without any visual context)
- [ ] Hook scoring was applied and the highest-scoring variant is listed first

**Hook scoring rubric check (apply to each variant):**
- [ ] Creates a knowledge gap (viewer thinks "wait, really?") — +1
- [ ] Under 12 words — +1
- [ ] Names the audience or a universal pain point — +1
- [ ] Avoids "in this video I will…" — +1
- [ ] Works without any visual context (audio-only test) — +1

---

## CTA Quality

- [ ] CTA is not "like and subscribe if you enjoyed this" (this converts near zero)
- [ ] CTA names a specific action: follow, comment, reply, watch part 2, etc.
- [ ] CTA matches the tone of the script (comment engagement for conversational content, subscribe ask for educational series)
- [ ] CTA does not exceed 15 words

---

## Script Quality

- [ ] No sentence in the script is longer than 15 words
- [ ] No jargon is used without a one-word definition immediately after it
- [ ] Every sentence delivers one discrete piece of value — no filler words
- [ ] No passive voice in the script ("This saves you time" not "Time can be saved by this")
- [ ] The script is fully self-contained — no external context required to understand it
- [ ] The core content is the correct mode (Summary or Question/Engagement) for the topic

---

## Output Format

- [ ] Output starts with `## YouTube Short Script — [Topic]`
- [ ] Tone is labeled explicitly
- [ ] Word count and estimated seconds are shown
- [ ] Hook Options section lists all 3 variants
- [ ] Full Script section uses one of the hook variants (labeled "using Hook N")
- [ ] Production Notes section is included (3–5 bullets: hook visual, overlays, cut points)
