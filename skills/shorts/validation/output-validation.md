# Shorts Output Validation

How to verify that a YouTube Short script is complete, correctly formatted, and ready to record.

---

## Structural Completeness Check

A complete script output must contain all of the following:

| Section | Required? | Minimum content |
|---------|-----------|----------------|
| Title header | Always | `## YouTube Short Script — [Topic]` |
| Tone label | Always | One of: Tech/Educational, Casual/Discovery, Dramatic, Controversial |
| Word count + seconds | Always | Format: `[N] words (~[N] seconds)` |
| Hook Options | Always | Exactly 3 hook variants, numbered |
| Full Script | Always | Hook + core content + CTA assembled, labeled "using Hook N" |
| Production Notes | Always | 3–5 bullets covering: hook visual, overlay, cut point |

---

## Word Count Validation

- [ ] Total word count is 70–80 words (count programmatically — do not estimate)
- [ ] Hook section: 8–12 words
- [ ] Core content section: 50–55 words
- [ ] CTA section: 12–15 words
- [ ] Sections sum to the total word count shown in the header
- [ ] The script was read aloud and completes in 28–32 seconds

**How to count:** Count every word in the Full Script (Hook + Core + CTA). Do not count section labels, markdown formatting, or Production Notes.

---

## Hook Validation

- [ ] Exactly 3 hook variants are provided
- [ ] All 3 variants are presented to the user (not pre-selected)
- [ ] No hook exceeds 12 words (count each one)
- [ ] No hook starts with "In this video", "Today I", or "Hi, I'm"
- [ ] The highest-scoring hook variant is listed first (re-rank if needed)
- [ ] At least one hook passes the audio-only test (makes sense with zero visual context)

**Score check for the lead hook (minimum 3/5):**
- [ ] Creates a knowledge gap
- [ ] Under 12 words
- [ ] Names the audience or universal pain
- [ ] Avoids "in this video" patterns
- [ ] Works audio-only

---

## CTA Validation

- [ ] CTA does not say "like and subscribe if you enjoyed this"
- [ ] CTA names a specific action (follow, comment with emoji, watch part 2, reply)
- [ ] CTA fits the tone (comment/question for conversational; subscribe/series for educational)
- [ ] CTA is 12–15 words

---

## Script Body Validation

- [ ] No sentence exceeds 15 words
- [ ] No jargon without an inline one-word definition
- [ ] No passive voice constructions
- [ ] No external context references ("as I showed last time", "if you've been following")
- [ ] Every sentence delivers one discrete piece of value (no filler)
- [ ] The script is fully self-contained — understandable on first view by a new viewer

---

## Final Readiness Gate

A script is ready to deliver when:

- [ ] Word count is 70–80 words and verified by count (not estimate)
- [ ] Three hooks are provided — none exceeds 12 words
- [ ] CTA is specific and not generic
- [ ] No passive voice in any sentence
- [ ] Read aloud test completed — fits 28–32 seconds
