# Exploring Protocol

## Goal
Find the best implementation approach before planning or coding.

## Workflow
1. Restate the goal and constraints in one sentence.
2. Run 2-3 targeted searches from primary sources.
3. Build a compact options table (2-4 options max).
4. Recommend one option tied to the user's constraints.
5. Ask for confirmation before planning/implementation.
6. Route: complex work -> planning; small bounded work -> implement.

## Options Table
| Option | Maturity | Complexity | Best For | Avoid If |
|---|---|---|---|---|

## Rules
- Keep results current and source-backed.
- Avoid framework/language bias unless requested.
- Do not present more than 4 options.

## Output Shape
```text
Outcome:
Goal:
Options:
Recommendation:
Decision Needed:
Next Step:
```
