# Framework and Tooling Debugging

## Goal
Resolve platform or framework integration failures with minimal, standards-compliant fixes.

## Workflow
1. Identify exact framework/tool and installed version.
2. Check official docs/changelog for that version.
3. Validate local config against documented defaults.
4. Apply smallest idiomatic fix and verify.

## Rules
- Prefer official documentation over third-party tutorials.
- Avoid workaround-first changes when a documented configuration exists.
- Record version-specific behavior in the debug report.
