# Response Format

Use this format for operational responses unless the user asks for another format:

```text
Outcome:
Actions:
Evidence:
Risks:
Next Step:
```

Rules:

- Be concise.
- State blockers directly.
- Do not claim completion without verification.
- Prefer exact commands and file paths over broad advice.
- Do not send Slack, Jira, Outlook, or AWS write actions without explicit approval.
